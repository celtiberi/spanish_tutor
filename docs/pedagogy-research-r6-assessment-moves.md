## The system diagnosis (why this is a real gap, not a feature wish)

1. **The ACTFL mode hole.** The character sheet tracks three modes:
   interpersonal (IP-01…08), interpretive (IT-01/02), presentational
   (PR-01). Pure conversation generates evidence for interpersonal
   ONLY. IT-01 ("get the gist of a short familiar-topic dialogue") and
   PR-01 ("produce a few practiced sentences about myself") are
   STRUCTURALLY untestable by chat — they sit unknown forever, the
   grades rail never moves them, and the XP can-do payer (known-gated)
   can never fire for a third of the sheet. Assessment moves are how
   those modes get evidence at all.
2. **Retrieval realization monotony.** P3 makes spaced retrieval THE
   durability event, and the scheduler queues due items — but the
   stance's only sanctioned realization is "a NATURAL Spanish elicit".
   One retrieval format = one retrieval direction exercised (see
   directionality below) and predictable, gameable practice.
3. **The quiz ban needs a boundary, not repeal.** The current ban
   (A/B English-meaning quizzes on KNOWN items; ≤1 comprehension check
   per 3 turns) was aimed at worksheet CHROME — low-information
   recognition theater on material already known. It has been read as
   "never test", which overshoots.

## The research-backed repertoire

| Move | What it tests | Key evidence |
|---|---|---|
| **Receptive recall** — "¿Qué significa «trabajo»?" | L2→L1 meaning link | Nation (2001/2013): word knowledge is multi-aspect; receptive and productive recall are DIFFERENT links. Webb (2005, 2008): learning/testing direction matters; each direction strengthens its own link |
| **Productive recall** — "How do you say 'I work' in Spanish?" | L1→L2 form link (harder, higher-value) | Webb directionality; testing effect strongest for effortful recall (Roediger & Karpicke 2006) |
| **Sentence translation, BOTH directions** | integrated form-meaning mapping | Cook (2010, *Translation in Language Teaching*): own-language use rehabilitated; translation is a legitimate, information-rich check, not a sin |
| **Elicited imitation** — "repeat after me: …" (sentence slightly beyond a chunk) | implicit grammar; parse-then-reproduce | Yan, Maeda, Lv & Ginther (2016, *Language Testing* meta-analysis): EI reliably indexes proficiency; Kim et al. (2024): web-delivered EI valid. TTS makes this deliverable here |
| **Dictation / mini-dictogloss** — hear a sentence (TTS), type it | decoding + noticing form | Wajnryb (1990) dictogloss; noticing hypothesis (Schmidt 1990) |
| **Paragraph gist + detail probes** — short text, "¿de qué habla?" then one detail Q | interpretive mode (IT-01!) | ACTFL IPA interpretive tasks; ties directly to the existing gist GAME |
| **Picture description** — teach image, "describe la foto" | presentational-ish production, vocabulary retrieval in context | OPI/IPA picture tasks; we already generate teach images |
| **Say-it-differently / paraphrase** | flexibility beyond memorized chunks | formulaic-to-creative progression (Myles); guards the "practiced phrases" ceiling in PR-01 |
| **Prepared monologue** — "tell me 3 sentences about your family" (then feedback) | presentational mode (PR-01!) | ACTFL presentational; the only honest PR evidence source |

## The balance laws (what keeps this from becoming a testing app)

1. **Conversation stays the vehicle (§1.2).** Assessment moves are
   BEATS inside the session — one move, then back to talk. Structured
   share already sanctioned by the 0.20/0.30/0.35/0.15 defaults.
2. **Mostly-success for novices (§2.8).** A check the learner will
   probably fail is a support decision, not a default; two failures →
   drop to recognition, bank a success. Desirable difficulty ≠
   drowning (Bjork; P6 affect).
3. **Mode-matched evidence (grading honesty).** A gist answer is
   IT evidence, never IP credit; a repeated sentence (EI) is weaker
   evidence than spontaneous production and grades accordingly
   (emerging at best). The band anchors already encode this — the
   repertoire note must say which moves license which sections.
4. **Variety is anti-Goodhart.** Rotating realization formats for due
   items prevents both learner pattern-matching and the fixation/
   probe-repeat failure the lite model shows under stress.
5. **The chrome ban STAYS.** A/B English-meaning recognition on known
   items remains banned; assessment moves must be able to FAIL
   informatively (recall > recognition, Kang 2013 within P3's frame).

3. **Amend the stance quiz-ban wording** to name its true target

   repertoire.
4. **Eval follow-up (booked):** persona-gate check that a 10-turn
   casey run contains ≥1 assessment move beyond conversational elicit;
   IT/PR sections gain evidence within N sessions of play.

## 4. Answers to the five open questions (evidence-bearing)

### Q1 — Webb directionality: mandate BOTH-direction rotation?

**No mandate. Soft variety preference only.**  
Webb supports: (a) receptive and productive knowledge are **not interchangeable**; (b) productive learning often yields broader gains; (c) test/practice direction shapes which link is trained. That warrants **occasional L1→L2 productive recall** and **not only L2→L1 meaning checks** — not a per-due-item both-direction schedule.

**Falsifier that would force a mandate:** a pre-registered within-learner result that single-direction natural elicits leave the opposite link unmeasurable after N sessions while dual rotation does not, at equal time-on-task. Absent that, **over-prescription**.

**Ruling:** REJECT both-direction *mandate*; ACCEPT directional *awareness* in the menu.

### Q2 — EI for A1 true beginners — too hard?

**Yes, without hard length/lexis gates.**  
Yan et al. 2016 supports EI as a **proficiency discriminator**, with **sentence length / complexity** as known sensitivity factors in the EI literature. For true-zero / early A1:

- Cap stimuli to **short, mostly-known lexis** (operational default: **≤6–8 syllables** or ≤~5–6 familiar words; no new morphology in the stimulus).  
- Prefer **after** some forms are mapped (not session-1 zero).  
- Pure accurate echo = **emerging max**, never `known`.  
- Fail twice → drop (already §2.8).

**Ruling:** ACCEPT EI on the menu with **A1 scaling gates**; reject unrestricted “slightly beyond a chunk” for true beginners.

### Q3 — Dictation via TTS unfair at A1?

**Can be unfair if rate/quality uncontrolled.**  
Listening is rate-sensitive; TTS prosody/rate is a documented product variable. Without slow A1 rate + one free repeat + non-harsh orthography grading (accents), failures confound **decoding tech** with **Spanish knowledge**.

**Minimum preconditions before defaulting dictation:** controllable slow rate; single short sentence; one replay; score meaning/segmental gist before accent perfection.

**Ruling:** ACCEPT as **optional, preconditioned** move; not default until TTS rate path is trusted.

### Q4 — Translate-a-paragraph vs CI / §2.3?

**Yes, risk is real at A1 if paragraph + full L1 product is routine.**  
Cook rehabilitates translation as a *type* of activity; P1 still needs comprehensible L2 as primary diet; §2.3 limits English jobs. Full paragraph L2→L1 translation floods L1 and can become dual-channel chrome.

**Safer stack:** (1) L2 gist (“¿de qué habla?”) → (2) one detail probe → (3) optional **single-sentence** translation of a known-heavy line. Full paragraph translation = rare stretch / late-A1, high-coverage text only.

**Ruling:** REJECT paragraph-translation as default repertoire item; ACCEPT sentence-level and gist-first variants.

### Q5 — Cadence vs ≤1 check per 3 turns?

**Keep the density hard cap; do not loosen.**  
“Every few turns when evidence is stale” is **looser and vaguer** than ≤1/3 if unconstrained, and **tighter** if “every few” means every 2 turns. Math:

- Cap ≤1 assessment/check beat per 3 turns ⇒ max density \(1/3 \approx 33\%\) of turns.  
- If “every 2–3 turns when stale” without a cap ⇒ can hit \(50\%\) assessment turns.  
- Form-focus hard breaks already claim ≤1/3. If assessment and form-focus stack, worst case \(\approx 2/3\) structured interrupts + uptake beats → conversation vehicle dies.

**Recommended rule (exact):**  
- **Hard:** ≤1 **assessment beat** per 3 teaching turns (same density class as the old comprehension-check cap).  
- **Trigger:** due/stale evidence **or** IT/PR starved — but still inside the cap.  
- **Non-stacking:** assessment beat and §2.5 form-focus hard break **do not both fire** on the same turn; prefer one.  
- **Never two failed assessment asks in a row** (§2.8).

**Ruling:** Cap **not looser** than current ≤1/3; stale is a *priority trigger inside the cap*, not a second channel.
